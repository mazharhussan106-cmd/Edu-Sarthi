cue: Which lightweight text format, built from curly braces and square brackets, do most web APIs use to send data?
category: Data format
frequency: Very high
importance: 5
origin: JSON grew out of JavaScript's object syntax in the early 2000s and became popular because it is easy for people to read and for programs to parse.
pro_tip: Use a JSON formatter or your browser's viewer to read long responses more easily.
memory_story: JSON is a neatly labelled box of boxes, where every item has a name tag.
visual: Curly braces holding named fields, with a square-bracket list inside one of them.
emotion: The ease of reading data that looks almost like plain English.
definition: JSON is a text format for data made of objects (name and value pairs), arrays (lists), strings, numbers, true or false, and null.
explanation: Objects use curly braces with double-quoted keys, arrays use square brackets, and values can be nested. JSON has no comments, no trailing commas and no single quotes for strings. Almost every language can convert JSON text into its own objects.
simple_explain: JSON writes data as named fields. For example {"name": "Asha", "age": 21} is an object with two fields, and a list is written in square brackets.
analogy: It is like a labelled box that can hold smaller labelled boxes.
formula_rule: {"key": value} for objects, [a, b] for lists
example_1: {"name": "Asha", "age": 21} is an object.
example_2: ["red", "green", "blue"] is an array of strings.
example_3: {"user": {"id": 7, "tags": ["new", "vip"]}} nests an object and an array.
related: parsing JSON, Content-Type, REST, XML
word_family: object, array, key, value, null
where_used: Almost every web API | Configuration files | Data exchange
mini_conversation: A: My JSON will not parse. | B: Check for single quotes or a trailing comma, since JSON allows neither.
misconception: ✗ JSON allows single quotes and comments like JavaScript → ✓ JSON requires double quotes for keys and strings and allows no comments or trailing commas
contrast: JSON vs a JavaScript object: JSON is text with strict rules, a JavaScript object lives in memory.
avoid: Do not hand-write JSON with trailing commas.
memory_trick: JSON needs double quotes and no trailing commas.
real_project: Reading a JSON response from an orders API and showing the items in a table.

mcq_why: JSON needs double-quoted keys and no trailing commas.
