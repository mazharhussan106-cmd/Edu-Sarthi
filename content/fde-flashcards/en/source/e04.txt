term: git fetch
cue: Which command lets you see new remote commits without changing any of your own files?
kind: Git command
frequency: High
importance: 4
origin: Fetch means to bring; Git downloads only new data from the remote into remote-tracking branches like origin/main and leaves your work alone.
pro_tip: Fetch before a pull and run git log HEAD..origin/main to see what is coming.
memory_story: Fetch is a postman who leaves the letters on your table without forcing you to open them.
visual: A delivery person leaves a parcel at the door and you open it later.
emotion: The safe relief of learning what is on the remote without touching your own work.
meaning: git fetch downloads new commits from the remote but does not change your branch or files.
code: git fetch origin¶git log HEAD..origin/main --oneline
output: 8b7d1e2 Fix refund rounding¶5c3a2f0 Update README
explanation: Fetch updates the remote-tracking branches. You can then look with git log or git diff, and decide whether to combine the changes with git merge or git rebase.
simple_explain: Fetch only brings the news of what is new on the remote. Your files do not change until you merge yourself, so it is safer than pull.
analogy: It is like visiting a shop to see whether new stock has arrived, without buying anything.
syntax: git fetch [<remote>]
anatomy: git fetch = command | <remote> = origin | --all = all remotes
example_1: git fetch origin
example_2: git fetch --all
example_3: git fetch --prune
variation: git fetch --prune   # clear deleted remote branches¶git fetch origin pull/12/head   # the code of PR 12
used_with: git merge, git rebase, --prune, origin/main
related: git pull, git merge, git log
alternatives: git pull (fetch plus merge)
word_family: git fetch, git pull, git merge, git remote, git push
where_used: Looking before a pull | Bringing a colleague's branch for review | CI scripts
mini_conversation: A: I am afraid pulling will break something. | B: Fetch first and check with log, then decide.
misconception: ✗ After git fetch my files change to include the new commits → ✓ Fetch does not change files, and new commits sit in origin/main until you merge or rebase
confused_with: git fetch vs git pull: fetch only downloads, pull downloads and merges.
avoid: Do not expect fetch to update your working files like pull does.
wrong_code: git fetch main origin
right_code: git fetch origin main
memory_trick: Fetch means just look, do not merge yet.
real_project: Fetching before a merge to see which new commits are on the remote.
real_interview: An interviewer may ask: What is the difference between fetch and pull?
real_daily: It is like checking whether new stock has come in without buying.

mcq_answer: C
