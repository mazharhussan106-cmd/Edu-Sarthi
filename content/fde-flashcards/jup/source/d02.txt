cue: Which key combinations make notebook work much faster?
category: Productivity

origin: Reaching for the mouse for every action is slow, so notebooks have two modes with single-key shortcuts.

visual: A cell with a blue border for command mode and a green border for edit mode.

definition: Notebooks have command mode, entered with Esc, for acting on cells, and edit mode, entered with Enter, for typing inside a cell, and each mode has its own shortcuts.
explanation: In command mode, A inserts a cell above, B inserts below, DD deletes the cell, M turns it into markdown and Y back into code. In both modes, Shift+Enter runs the cell and moves on, and Ctrl+Enter runs it and stays. The shortcut list is available from the command palette, and exact keys may differ slightly between interfaces and versions.
simple_explain: Press Esc to control cells and Enter to type, then use single keys for common actions.
analogy: Command mode is the remote control, and edit mode is the keyboard in your hand.
formula_rule: Esc to command, Enter to edit, Shift+Enter to run.
example_1: Pressing B to add a cell under the current one.
example_2: Pressing M to switch a cell to text.
example_3: Pressing Shift+Enter to run and move down.
related: cells, markdown cells, restart and run all, JupyterLab
word_family: shortcut, command mode, edit mode, palette, key

avoid: Do not type letters in command mode, because they trigger actions.

term: Magic commands
cue: Which special commands starting with percent signs add extra notebook features?
kind: Command
frequency: High
importance: 4
origin: Common chores such as timing code or listing files deserved shortcuts that are not part of the language itself.
pro_tip: Use a single percent for one line and a double percent for the whole cell.
memory_story: Magic commands are notebook buttons that you press by typing a word.
visual: A cell starting with a percent sign above a timing result.
emotion: The satisfaction of a handy shortcut that just works.
meaning: Magic commands are special instructions of the IPython kernel, where line magics start with one percent sign and cell magics start with two, and they handle tasks like timing, file listing and loading.
code: # cell 1¶%timeit sum(range(1000))¶%pwd¶%who¶# cell 2 (a cell magic must be the first line of its cell)¶%%time¶total = sum(range(100000))
output: Cell 1 shows the average run time, the current folder and a list of variable names. Cell 2 shows the wall time for the cell.
explanation: Line magics act on the rest of the line, and cell magics act on the whole cell. Useful ones include timeit for repeated timing, time for one run, pwd for the folder, who for variables, load for pulling a file into a cell and run for running a script. A leading exclamation mark runs a shell command instead. Magics work in IPython kernels only, not in plain Python scripts.
simple_explain: Percent commands are notebook extras for timing, files and variables.
analogy: Magic commands are notebook buttons that you press by typing a word.
syntax: %name arguments | %%name
anatomy: % = line magic | %% = cell magic | name = action | arguments = input
example_1: Timing a function with timeit.
example_2: Showing the current folder with pwd.
example_3: Listing all variables with who.
variation: !ls to run a shell command   // exclamation mark instead of percent
used_with: IPython kernel, timing, files
related: performance and memory, installing packages, shortcuts, nbconvert
alternatives: Python time module | Terminal commands
where_used: Profiling | File checks | Quick tools
mini_conversation: A: How long does this step take? | B: Put %%time at the top of the cell.
misconception: ✗ Magic commands work in any Python file → ✓ They only work inside IPython based notebooks and shells
confused_with: %timeit vs %time: many repeated runs versus one run.
avoid: Do not paste magic commands into a normal script file.
wrong_code: time sum(range(1000))
right_code: %time sum(range(1000))
memory_trick: One percent for a line, two for the cell.
real_project: A %%time check showed that one loading step was taking most of the run.
real_interview: An interviewer may ask: What is the difference between % and %% magics?
real_daily: It is like a stopwatch built into your pen.
mcq_question: Which prefix makes a cell magic?
mcq_options: A) Two percent signs B) Two hash signs C) Two ampersands D) Two at signs
mcq_answer: A
mcq_why: A double percent sign applies to the whole cell.
fill_blank: A leading exclamation mark runs a ____ command → shell

visual: A package box arrowed into the kernel's environment.

analogy: The percent pip command always delivers the parcel to the house where the kernel lives.
