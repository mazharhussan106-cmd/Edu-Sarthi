topic: 01 Basics
level: Beginner
term: What an LLM is
cue: Which kind of model predicts text and can follow instructions?
category: Core concept
frequency: Very high
importance: 5
origin: Researchers trained very large neural networks on huge amounts of text to predict the next piece of text, and found they could follow instructions and answer questions.
pro_tip: Think of an LLM as a very capable text predictor, not a database of verified facts.
memory_story: An LLM is a very well-read assistant who writes fluent answers from patterns it learned, without looking anything up unless you give it tools.
visual: Text going into a model box and a continuation coming out.
emotion: The wonder of a machine that writes useful text.
definition: A large language model is a neural network trained on large text collections that generates text by predicting likely next tokens, and is adapted to follow instructions and hold conversations.
explanation: The model has fixed knowledge up to its training cut-off and no live access to the internet unless tools are provided. It does not look up facts but produces likely text, so it can be wrong while sounding confident. Behaviour depends on the prompt, settings and context. Applications wrap the model with instructions, data and tools.
simple_explain: An LLM generates text from your prompt using patterns learned in training, and it can be wrong.
analogy: An LLM is a well-read assistant who writes fluent answers from learned patterns and checks nothing unless given tools.
formula_rule: Prompt in, predicted text out.
example_1: Summarising a pasted email.
example_2: Drafting a reply in a given tone.
example_3: Classifying a ticket by topic.
related: tokens, context window, hallucination, grounding
word_family: model, prediction, training, inference, instruction
where_used: Assistants | Automation | Customer tools
mini_conversation: A: Does the model know our latest policy? | B: Only if we put it in the prompt, since its training is fixed.
misconception: ✗ An LLM looks up facts like a search engine → ✓ It generates likely text and can be wrong without any lookup
contrast: LLM vs search engine: one generates text, the other retrieves existing documents.
avoid: Do not treat model output as verified fact.
memory_trick: Fluent does not mean correct.
real_project: Explaining that the model needed the policy text in its prompt resolved a customer's wrong answers.

cue: Which limit says how much text the model can consider at once?
category: Core concept

origin: Models can only attend to a fixed amount of text per request, so every call has a maximum size.

memory_story: The context window is the size of the desk where the model spreads all its papers for one job.

emotion: The awareness of exactly how much text fits.
definition: The context window is the maximum number of tokens, covering the prompt, history and output, that a model can process in one request.
explanation: Everything the model should use must fit in the window, including the system prompt, previous messages, retrieved documents and the reply. Larger windows allow longer documents, but cost more and may reduce attention on details in the middle. Overflow causes errors or truncation. Strategies include summarising history, retrieving only relevant parts and splitting work. The model has no memory beyond what you send each time.

category: Core concept

Higher values increase variety and risk of odd answers. Top-p and top-k limit the pool of tokens. Some models fix these settings. Change one setting at a time, and test on examples.

formula_rule: Low = predictable. High = varied.
