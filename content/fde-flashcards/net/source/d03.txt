definition: An SSH tunnel forwards a local or remote port through an encrypted SSH connection, so traffic reaches a service on the far side.
explanation: A local forward opens a port on your machine, such as 5433, and sends connections through the SSH server to a target like db.internal:5432. A remote forward does the reverse. Dynamic forwarding makes a SOCKS proxy. Tunnels are handy for debugging but can bypass controls, so teams should know when they are used and avoid leaving them open.
simple_explain: ssh -L opens a local port that leads through the server to a private service.
analogy: An SSH tunnel is a pipe laid inside an encrypted cable.
formula_rule: Local port → SSH server → target host and port.
example_1: ssh -L 5433:db.internal:5432 bastion
example_2: A remote forward exposing a local web app temporarily.
example_3: ssh -D 1080 for a SOCKS proxy.
