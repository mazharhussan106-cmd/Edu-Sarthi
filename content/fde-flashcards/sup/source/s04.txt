The database reads the token to know who is calling, which is what lets Row Level Security policies use auth.uid(). You can enable providers and email settings in the dashboard.
simple_explain: Auth creates and checks user accounts for you. After login your app holds a token, and the database uses it to know which user is asking.
analogy: It is like front-desk security that checks identities and hands out passes to the rest of the building.

example_3: A profiles table whose id equals the user's id in auth.users.
related: sessions and JWT, Row Level Security, OAuth, magic links
word_family: auth.users, session, token, provider, JWT
where_used: Any app with accounts | Per-user data | Social login
