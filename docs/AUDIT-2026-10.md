# Full-project audit — 6 Oct 2026

Five parallel reviews (security/auth, data & Prisma, deck/library flow, UI/accessibility/CLAUDE.md rules, compliance/ops). Fixes were verified with `tsc`, `next build`, scripted tests against a local Postgres, and a real-login forgery test.

## Fixed in this pass

**Security / accounts**
- Session could be told it was email-verified by the client → now re-read from the database on update; token life 7 days.
- Suspended or unverified users could still call upload, submission, deck, like, report, institute and profile APIs → shared `lib/apiUser.ts requireUser`.
- Unverified account proven by inbox now drops the old password and burns reset tokens (account-takeover path).
- Verification attempts are counted atomically (no parallel guessing).
- Reset-link base URL throws in production if `NEXT_PUBLIC_APP_URL` is missing; 60 s cooldown on forgot-password.
- Teacher/admin pages re-check role and suspension on every page; teachers see only unassigned or own-assigned submissions of a student.
- Site-wide headers: `frame-ancestors 'self'`, `nosniff`, Referrer-Policy, Permissions-Policy.
- Admin CSV export blocks `\t` / `\r` formula tricks; admin log no longer stores student emails.

**Data**
- Account deletion no longer fails for institute applicants (`applicantId` nullable, `SetNull`).
- Deletion is wrapped and redacts admin-log detail. Retention only blanks rows whose files were actually deleted; expired verification/reset rows are swept by the cron.
- Ten new indexes (CardState, Submission, Feedback, AdminLog, DeckLike, DeckReport, Institute, Word).
- Feedback claim is re-checked inside the transaction (409 if lost); duplicate submission key handled.
- Admin content API maps missing/linked rows to 404 instead of 500.

**Decks / library**
- Deck limits and creation run under an advisory lock (no racing past the limit).
- Edits to published decks go back to review *before* the write.
- Copy: files copied 8 at a time, limit enforced under lock, copied files removed on failure, topic kept.
- Institute leave/drop restores the right visibility and clears the share link; rejected decks lose the link.
- Library deck page: light index query, imported decks listed by topic, hand-made decks paged by 25.
- Suspended owners' decks are hidden from the library.
- Excel import: answer letter must be a real option, skipped sheets are reported, sequential order across sheets, 5,000-row sheet cap.
- "Started" now means reviewed at least once, so tagging a card no longer uses the daily quota; repeat taps within 8 s are ignored; due labels round up.

**UI / rules**
- Loading and error screens for every route group, and a not-found page.
- `text-mist` → `text-ink-muted` (contrast), `border-ink/30` → token, `focus:outline-none` removed from 16 files so the focus ring shows.
- Privacy page and FAQ copy made accurate (admins, teacher-deck recordings, YouTube/Drive, 90-day recording deletion, account deletion). Register page has a consent / under-18 line.
- Teacher student list paginated (50 per page); admin lists capped.
- CI workflow added (prisma generate, tsc, build); Database-setup workflow serialised; Android `allowBackup=false`; `middleware.ts` → `proxy.ts` (Next 16 name).
